Aplikasi Android berbasis Kotlin yang dibangun untuk memenuhi Tugas Praktikum Pemrograman Aplikasi Bergerak (Pertemuan 3). Aplikasi ini mendemonstrasikan penggunaan Explicit Intent untuk navigasi halaman dan transfer data, serta Implicit Intent untuk interaksi dengan aplikasi sistem eksternal.

## Fitur Utama

- Form Input Profil: Input data nama, email, nomor telepon, dan URL portofolio dengan validasi dasar.
- Explicit Intent: Mengirim data dari form utama (`MainActivity`) ke halaman profil (`ProfileActivity`).
- Implicit Intent:
  - Membuka URL portofolio di browser bawaan.
  - Mengarahkan nomor telepon ke aplikasi dialer.
  - Membagikan rincian profil ke aplikasi lain via Share Sheet.

## Teknologi & Alat

- Bahasa Pemrograman: Kotlin
- Min SDK: API 24 (Android 7.0 Nougat)
- UI Components: Material Design 3, ConstraintLayout, ScrollView

## Cara Menjalankan Proyek

1. Clone repositori ini:
   git clone https://github.com/Yukomyy/pemrograman-aplikasi-bergerak-p3.git
2. Buka Android Studio lalu pilih "Open" dan arahkan ke folder hasil clone.
3. Tunggu hingga proses Gradle Sync selesai.
4. Jalankan aplikasi pada emulator atau perangkat fisik Android.
